# org.openmarkov.io.database.elvira — Architecture

**Role in the project:** Reads case databases from Elvira's legacy database format for use in learning algorithms.
**Source files:** ~5 Java files
**[← Back to overall architecture](../ARCHITECTURE.md)**

---

## What This Module Does

**Elvira** is a legacy Bayesian network tool developed in Spain in the 1990s and 2000s. Because OpenMarkov's predecessor project was closely related to Elvira, it supports Elvira's native database format (`.dbc`) for importing case data into learning algorithms.

---

## Elvira Database Format

Elvira database files are plain-text files with a structured syntax:

```
// Elvira format database
// Autogenerated
node-name-1  node-name-2  node-name-3
state-a      state-x      state-1
state-b      state-y      state-1
state-a      state-x      state-2
```

The first non-comment line lists variable names (tab-separated). Each subsequent line is one case.

## Key Class

| Class | Role |
|-------|------|
| `ElviraCaseDatabaseReader` | Implements `CaseDatabaseReader`; reads `.dbc` → `CaseDatabase` |

---

## How It Works

1. Skip comment lines (starting with `//`).
2. Parse the header line to identify variable names.
3. Match each column to the corresponding `Variable` in the network.
4. Parse each data line, converting state names to integer indices.
5. Return a `CaseDatabase`.
